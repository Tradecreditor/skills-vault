一行指令，讓 Claude Code 跟 Codex 一起寫 code

讓不同的 AI 互相討論，就像吃台菜要配白飯，已經是 AI 時代的基本技能。

用 herdr，Claude Code 就會開一個 Codex 視窗，兩個 AI 在你眼前對話，看得到也能隨時介入。不像 Codex rescue 或 subagent，過程無法直接介入。

用途很多：
• Code review：讓它們互相挑錯，過程都看得到、可介入
• 交叉驗證：教學投影片、報告、報表，讓它們互相確認、可介入

底層邏輯：herdr 開一個 socket API，幫 AI 在對方的終端機打字、再把畫面讀回來。這麼輕量的方式，之後應該會是工程師、AI 使用者的基本環境。
