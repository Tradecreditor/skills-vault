Post 1 — @rico.ai.solo (https://www.threads.com/@rico.ai.solo/post/DeBUAFsH310):

無論 Grokbot 還是 Claude，記得要Backup你已經建立好的東西，隨時在突發情況抽身離開。￼￼方法同流程如下，可以參考一下:

1. 確認你最常用的流程，以及最大工作量的流程。因為那些簡單的流程，相信新的 agent 都很容易能夠製作出來，不需要特別打包

2. 叫你嘅Agent將佢打包成一個 Zip 檔，用Skill 的格式去打包。可以用 Skill.md 清楚列明整個流程，同時間亦要將相關的程式碼（例如一些 Python Script）打包放進一個 script folder 當中。

3. 你可以選擇將個 zip 檔傳到你的 Google Drive，又或者不用zip檔的話，技術性一點，將它的更新全部更新上去Github。

4. 我個人會盡可能將所有流程變成 Python script 。 一來，可以控制程式碼AI 的輸出，平日確保穩定；二來，打包和備份都相對簡單清晰。不過呢個方向係比較適合技術型嘅玩家。
