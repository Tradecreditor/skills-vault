① Logo 描邊動畫 讓 Logo 線條慢慢被「畫出來」，最後再淡入品牌名稱。

很適合： ・網站開場 ・品牌 Logo 動畫 ・簡報片頭

② Loading 動畫 像是三個圓點依序跳動、淡入、縮放。

這類動畫最重要的是「節奏」。

如果三個元素同時動，很容易看起來很亂；把每個元素的開始時間錯開，整體質感差很多。

③ 動態長條圖 直接丟資料給 Claude，例如：

A = 20 B = 40 C = 60

就可以讓長條依序從 0 長到指定數值。

拿來做數據簡報、產品 Demo、Landing Page 都很好用。

真正影響結果的，其實是 Prompt 有沒有講清楚這 5 件事：

「主體、畫布、動作、順序、輸出」

例如不要只說：

「幫我做一個有質感的 Logo 動畫。」

可以改成：

「16:9 深色背景，Logo 線條用 2 秒描繪完成，再用 0.5 秒淡入品牌名稱，最後停止，輸出成單一 HTML。」
