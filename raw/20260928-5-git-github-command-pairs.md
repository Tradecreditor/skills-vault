This is Merge. This is Rebase. What's the difference? Merge combines your branch with another and can create a new commit joining both histories. Rebase replays your commits on top of a new base, leaving the history as one straight line. This is Fetch. This is Pull. What's the difference? Fetch downloads the newest commits from the remote without changing anything in your current branch. Pull does that same download, then automatically integrates those changes into the branch you're currently working on. This is Reset. This is Revert. What's the difference? Reset moves your branch pointer back to another commit, changing which commits the branch includes. Revert keeps all your existing history and adds a new commit that undoes an earlier one. This is a fork, this is a clone. What's the difference? A fork creates your own copy of a repository on GitHub, separate from the original. A clone downloads that repository onto your computer so you can work with it locally. This is a merge commit, this is a squash merge. What's the difference? A merge commit keeps each pull request commit and joins the two branch histories. A squash merge combines those commits into one single commit on the target branch. Follow for more.
