## 摘要

@nocodealex 分享了 4 個免費設計資源網站，專為使用 Claude 進行 vibe coding 的開發者而設。核心洞見是：Claude 擅長模仿它能看到的東西，但無法憑空發明品味——所以需要給它好的視覺參考。這些網站提供精選優質網站截圖、可複製貼上的 UI 過渡動畫、App 推廣影片生成器，以及真實品牌的簡報範本。全部免費使用，有助於讓 vibe-coded 產品脫離千篇一律的紫色漸層風格。

## Key facts

- **godly.design** — curated gallery of the best-designed websites; screenshot any site and paste into Claude: "match the layout, spacing and type — not the brand, the decisions"
- **transitions.dev** — copy-paste UI transitions (menus, modals, number pop-ins, success checks); also ships as a Claude Code skill with 27+ transitions built in
- **animos.app** — turn app screenshots into a looping launch video in the browser; 25 templates, no editing skills needed
- **deck.gallery** — 200+ real pitch decks and 9,000+ slides from brands including OpenAI and Perplexity; borrow structure, not content
- All 4 are free; paid tiers exist but are not required
- Key technique: screenshot → paste into Claude → "match the decisions: spacing, type size, one accent color"
- None of the tools are sponsored

## 點解值得留意

- Claude 模仿視覺參考比憑空創作設計更可靠——截圖工作流程能直接套用到 Iron Log 或 English Overload 的 UI 改版
- transitions.dev 的 Claude Code skill 整合是即插即用的方案，可讓 agent 掌握 27+ 種 UI 過渡效果而不需逐一解釋
- deck.gallery 可用於 Josep 準備任何 pitch 或演示材料，借用成熟品牌的簡報結構
- 整套方法論（給 Claude 看得到的東西）可作為 agent-based UI 開發的標準 SOP
