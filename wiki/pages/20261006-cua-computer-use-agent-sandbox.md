## 摘要
呢條 Instagram reel 介紹開源項目 Cua（GitHub 25,000+ stars），概念係俾 AI agent 一部獨立嘅電腦，而唔係同用家搶同一個螢幕同滑鼠。喺 Mac 上，repo 內嘅免費工具 Lume 可以喺 Mac 入面開一部完整虛擬 Mac 俾 agent 用；需要多部就可以租雲端桌面，一次過管理一隊 agent。亦有 driver 可以喺背景操作，唔會搶走滑鼠。用途包括測試 app、從冇 API 嘅網站攞資料、同埋一邊做嘢一邊跑 job。

## Key facts
- Cua: open-source, free; "over 25,000 stars" per the reel (not verified against GitHub).
- Lume: free tool in the repo that runs a full virtual Mac inside a Mac.
- Cloud desktops are offered as a paid rental for running multiple agents.
- A driver lets the agent operate in the background without taking over the mouse.
- Use cases named: app testing, extracting data from sites without an API, background jobs.
