## 摘要
Nick Saraev 介紹開源模擬引擎 MiroFish，聲稱 GitHub 已過 8 萬 star。用家上載產品點子、pitch 或粗略 MVP，系統就會建立一個由模擬 AI 人物組成嘅數碼世界，每個角色有自己嘅性格、背景同意見。呢班角色會喺模擬社交平台上互相反應同辯論，好似自動運行嘅 focus group。完成後會出報告，講邊啲位被喜歡、邊啲被討厭、想點改，仲可以逐個角色對話追問原因。適合想喺開發前低成本驗證點子嘅創業者。

## Key facts
- Tool: MiroFish, open source simulation engine (claimed 80K+ GitHub stars; not verified here).
- Flow: upload idea / pitch / rough MVP -> generates a simulated society of AI personas -> they discuss it on a simulated social platform -> full report (why loved, why hated, requested changes).
- You can chat with any single simulated persona to ask why they reacted that way.
- The reel gives no repo URL or install command; the link is delivered by DM after commenting "STARTUP" (lead-magnet teaser). Find the repo via GitHub search for "MiroFish".

## 點解值得留意
- 可用嚟喺開工前模擬市場反應，驗證 Jeff 嘅產品點子。
- 多代理社交模擬係值得追蹤嘅 agent 應用方向；建議之後搵 repo 補一個 stars 頁。
- 注意：模擬 persona 嘅意見未必代表真實客戶，要同真人訪談對照。
