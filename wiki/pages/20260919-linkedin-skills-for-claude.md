## 摘要

LinkedIn Skills for Claude 係一個免費開源工具，擁有超過 2,000 個 GitHub Stars，提供 12 種不同技能自動化 LinkedIn 工作流程。用家可以用它撰寫有效的貼文 Hook、分析互動用戶並分類整理、清理 AI 生成的文字令其更自然。工具以 Claude 作為底層 AI 引擎，設計給想節省 LinkedIn 自動化訂閱費用的用戶。適合 LinkedIn 創作者、B2B 銷售人員及個人品牌建立者。

## Key facts

- **Name:** LinkedIn Skills for Claude
- **License:** Free, open-source
- **Stars:** 2,000+ GitHub stars
- **Skills count:** 12 different skills
- **Platform:** Works with Claude (Claude Code / Agent Skills)
- **Capabilities:**
  - Create posts with proven hook formulas
  - Analyze people engaging with your content
  - Organize engaged users into useful categories
  - Clean up AI-generated writing to sound more natural
- **Install:** `npx skills add` (standard Agent Skills install pattern)

## 點解值得留意

- 完全免費替代 LinkedIn 付費自動化工具（如 PhantomBuster、Dux-Soup），對 skills-vault 的讀者有直接節省成本意義。
- 示範了如何用 Claude Agent Skills 架構建立 12 個垂直平台技能，是研究 skills 設計的好範例。
- 2,000+ stars 表明社群採用率高，值得追蹤後續更新。
- 與 skills-vault 本身的 `vault-capture`、`reviewing-supabase-rls` 等 skill 設計理念一致，可作為 gerund-named skill 的參考案例。
