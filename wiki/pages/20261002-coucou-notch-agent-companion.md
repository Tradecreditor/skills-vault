## 摘要

Coucou 係一隻住喺 Mac notch（Windows / Linux 係螢幕頂部）嘅小角色 Mochi，幫你睇住 Claude Code、Codex、Cursor、Gemini CLI、Antigravity 等 agent session：睇住佢哋讀咩、改咩、行咩，permission request 直接喺 notch 撳 Allow / Deny，亦可以拖檔案入去問 Claude。Swift 6 / SwiftUI（macOS）加 Tauri 2（Windows / Linux），MIT。2026-09-27 建立，GitHub 單平台入選，窗口內冇驗證到 X 數字。

## Key facts

- **What**: macOS (Swift 6 / SwiftUI) and Windows/Linux (Tauri 2) companion app; MIT.
- **Agents**: live session view for Claude Code, Cursor, Codex, Gemini CLI, Antigravity; any agent can get a pill by tagging its hook payload with `coucou_agent` (see `docs/AGENTS.md`).
- **Approvals**: Claude Code and Codex permission requests appear with Allow / Deny (Always for Claude Code) in the notch.
- **Extras**: chat with Claude (Gemini/OpenAI with your own keys, macOS), drop a file on the notch, integrations (Stripe, n8n, GitHub, Vercel, Resend, Notion, Cal.com).
