呢條 Instagram Reel 介紹 Google 開源嘅 Harness²：唔使重新訓練模型，agent 就可以升級自己嘅 harness。佢會提出對 prompt、工具、記憶同 skills 嘅修改，喺同一任務上測試，保留有效嘅改動，並將每次任務嘅教訓儲起，令下一輪改進起步更好。作者話同一個模型下，一輪改進最多可提升 11.5 分 benchmark。Caption 冇附連結（要留言 "HARNESS" 先收到 GitHub link）。

## Key facts
- Harness²: Google open-sourced harness that edits an agent's prompts, tools, memory and skills, tests on the same task, keeps what worked.
- Stores lessons from each task so later rounds start smarter.
- Claimed: up to +11.5 benchmark points in one round with the same model (creator's claim; check the repo/paper).
