## 摘要
呢個係 OWASP 官方嘅《Secure Coding Practices Quick Reference Guide》,一份與技術無關、以檢查清單形式列出嘅安全編碼實務指南,方便開發團隊喺整個開發生命週期入面快速套用。內容涵蓋軟體安全原則概論、安全編碼實務清單同重要術語詞彙表,重點放喺「應該點做」而唔係逐項列舉具體漏洞或攻擊手法。呢個 GitHub repo 而家已經封存(archived),內容已遷移去 OWASP 官方項目頁面,分為穩定版(stable)同草稿版(draft),並提供多國語言版本包括英文、西班牙文、韓文、葡萄牙文同中文。
