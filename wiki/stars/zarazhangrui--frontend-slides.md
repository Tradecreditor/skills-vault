## 摘要

Frontend Slides 是 Claude Code 外掛技能，幫助非設計師快速建立美觀的網頁簡報。無需 CSS/JavaScript 知識，採用「視覺化選擇」方式讓使用者挑選喜歡的設計風格。支援 PowerPoint 轉換、零依賴（單一 HTML 檔案）、無 AI 俗套設計、可高度客製化。生成的簡報為生產品質，內嵌 CSS/JS，可直接分享。

## Key facts

- **Install**: `/plugin marketplace add https://github.com/zarazhangrui/frontend-slides`
- **Language**: Python / HTML / CSS / JavaScript
- **License**: MIT
- **Built for**: Claude Code plugin / Agent Skills
- **Key feature**: Visual style discovery, PPT conversion, production-quality HTML output
- **Zero dependencies**: Single HTML files with inline CSS/JS

## 點解值得留意

Frontend Slides 降低建立專業簡報的門檻，特別適合需要快速製作演示的開發者和內容創作者。「反 AI 俗套」的設計理念避免了通用 AI 美感，而視覺化風格選擇讓非設計師也能做出專業作品。完整支援 PowerPoint 轉換，生成的簡報是單一 HTML 檔案，便於分享和修改。作為 Claude Code 正式外掛，整合緊密。
