## 摘要

html-ppt-skill 係一個界面畀 AI agent 用嘅 HTML 簡報生成 Skill,一鍵就可以整出專業感嘅靜態網頁簡報,唔使起 build,純 HTML/CSS/JS 就搞掂。內置 36 個主題、15 個完整 full-deck 範本、36 種單頁版面同 47 種動畫(27 個 CSS 動畫 + 20 個 canvas FX 特效),仲有全新嘅「演講者模式」:按 S 鍵開一個獨立視窗,四張可拖拉嘅磁性卡片同時顯示目前頁、下一頁預覽、逐字講稿同計時器,兩個視窗用 BroadcastChannel 保持同步。安裝方式除咗 `npx skills add` 之外,仲支援手動複製資料夾去 Claude Code、Codex、Cursor 等唔同 agent 嘅 skills 目錄,亦可以喺完全冇網絡嘅環境下離線運作(只有 Google Fonts 呢個遠端依賴會 fallback 返用系統字體)。
