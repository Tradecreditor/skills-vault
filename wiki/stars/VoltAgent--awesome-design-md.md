## 摘要
呢個 repo 收錄咗一系列 DESIGN.md 檔案 —— DESIGN.md 係 Google Stitch 提出嘅新概念,一份純文字嘅設計系統文件,等 AI agent 讀完就知道個網站/產品應該點樣設計、配色同排版。同 AGENTS.md 教 coding agent 點樣起專案嘅思路類似,DESIGN.md 就係教 design agent 個 UI 應該點睇點感覺,唔使 Figma 匯出或者 JSON schema,直接一個 markdown 檔搞掂。項目已經由 70 幾個真實網站(包括 Stripe、Apple、Notion、Vercel 等)入面拆解出佢哋嘅視覺語言,做成即攞即用嘅 DESIGN.md 檔案,每個檔案仲附埋 HTML 預覽頁,方便直接複製去自己項目 root 度俾 AI agent 讀取。

## 點解值得留意
呢個係 AGENTS.md / CLAUDE.md 呢類「agent 讀嘅設定檔」概念延伸去視覺設計層面嘅一個好例子,同 skills-vault 本身「一份 markdown 教 agent 點做嘢」嘅精神好夾。對於想快速做出風格一致 UI 嘅 vibe coding 場景特別有用 —— 攞一個現成品牌嘅 DESIGN.md 掉入項目,叫 agent 「幫我整個似呢個風格嘅頁面」就得,唔使自己由零砌設計系統。
